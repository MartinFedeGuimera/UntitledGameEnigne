# UntitledGameEnigne

A simple 2D **Game Engine**, with some Games to show it's features.

---

## Features

- Creating *Scenes* and *GameObject*s.
- Adding *Components* to these *GameObject*s.

---

## Technologies

- C#
- OpenTK

---

## Installation

1. Clone the repository:
```bash
git clone https://github.com/MartinFedeGuimera/UntitledGameEngine.git
```
2. Open the project with your favourite text editor.

---

## How To Use
- As **UntitledGameEngine** doesn't have a finished desktop version or neither a way to use it as a library, you can extract the usefull classes and functions of *Pong.sln*
